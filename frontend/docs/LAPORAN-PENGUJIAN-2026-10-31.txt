ALUR UTAMA YANG BERHASIL DIJALANKAN
1. Login warga -> buat persiapan KK baru -> konfirmasi kebutuhan -> isi data -> unggah berkas -> tinjau ringkasan -> setujui pembagian -> kirim ke petugas.
2. Logout warga -> login petugas -> cari kiriman -> buka file warga -> mulai tinjauan -> minta revisi dengan alasan dan tindakan.
3. Login warga -> ganti file menjadi v2 -> kirim ulang pada permintaan sama -> riwayat v1 tetap tersimpan.
4. Login petugas -> mulai tinjauan ulang -> nilai data dan dokumen secara eksplisit -> isi catatan -> selesaikan tinjauan.
5. Login warga -> konfirmasi penerimaan hasil layanan pemerintah -> status tinjauan tetap SELESAI dan status hasil pemerintah tersimpan terpisah.
6. Reload mempertahankan kiriman, riwayat, dan hasil tinjauan.
